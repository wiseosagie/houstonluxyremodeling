# SEO Tracking — Houston Organic Growth

Baseline template for monthly SEO review. Fill in actual values from Google Search Console and
GA4 each month — do not fabricate figures. Leave a metric blank rather than guessing if data
isn't available yet.

## How to Update This Monthly

1. Google Search Console → Performance → filter by page, date range = last 28 days.
2. Record impressions, clicks, CTR, and average position for each URL below.
3. GA4 → look at organic sessions and, if consultation-start/consultation-submit events are
   configured (see `docs/ANALYTICS_EVENTS.md`), filter those events to `sessionDefaultChannelGroup
   = Organic Search` for the same URLs.
4. Note any ranking or indexing issues in the "Notes" column.

## Review Checklist Each Month

- [ ] Any page with impressions but near-zero CTR? Revisit title/description.
- [ ] Any page stuck outside page 1 (position > 10) after 8+ weeks indexed? Consider content gap
      vs. current top-ranking pages.
- [ ] Any new People Also Ask / related-search patterns worth a content update or FAQ addition?
- [ ] Any cannibalization signal — two of our own URLs both showing impressions for the same
      query? Consolidate per `docs/SEO_KEYWORD_MAP.md`.
- [ ] Re-evaluate the Next-Wave Candidates list in `docs/SEO_KEYWORD_MAP.md` against this month's
      impression data.
